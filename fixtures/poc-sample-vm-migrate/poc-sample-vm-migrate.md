# poc-sample-vm-migrate

- Open the VM list and pick the running VM to migrate

![poc-sample-vm-migrate-00](poc-sample-vm-migrate-00.png)

- Open **Actions** > **Migrate** on the VM

![poc-sample-vm-migrate-01](poc-sample-vm-migrate-01.png)

- Choose the target host in the same cluster

![poc-sample-vm-migrate-02](poc-sample-vm-migrate-02.png)

- Confirm the migration in the dialog

![poc-sample-vm-migrate-03](poc-sample-vm-migrate-03.png)

- The task list shows the migration running

![poc-sample-vm-migrate-04](poc-sample-vm-migrate-04.png)

- The VM is Running on the target host

![poc-sample-vm-migrate-05](poc-sample-vm-migrate-05.png)
